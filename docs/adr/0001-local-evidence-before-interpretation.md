# Prepare evidence locally; interpret it in the coding agent

The user chose ordinary macOS recordings and local preprocessing in the
SpeechCatcher discussion, carried into this project on 2026-10-09. Preserve the
original recording and its timeline; prepare transcripts and retrievable frames
locally, then let the coding agent interpret selected evidence. This avoids making
a cloud video-analysis service or custom recorder part of the required workflow,
at the cost of maintaining local media and transcription tooling; text and images
supplied to Codex still become input to its model.
